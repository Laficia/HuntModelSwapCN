# 狩猎模型替换 HuntModelSwapCN

独立于 HHT 的国服卫月插件。可以替换战斗小怪或可攻击木人为指定 S/A/B、SS 或 SS 随从狩猎外观，也可在面前生成本地预览；支持名字、等级、体型、原版头标、隐藏模型和对应技能演示。

当前版 0.1.0.20 继续修复庭具木人替换后，点击模型和「选中木人」均无效的问题。上一版仍禁用了原木人的绘制并设置隐藏模型标志，导致原生可选中判断失败；现在只隐藏庭具布局图形，真实木人保持原有模型、体型和绘制状态，仅更新目标栏的名字、等级和头标。点击模型继续转交给真实木人。编译零警告，4924 项离线检查通过；游戏内选中与攻击效果仍需验证。

## 使用

在线安装：在卫月设置的「第三方插件库」中添加以下订阅地址，保存后到插件安装器搜索「狩猎模型替换」安装。输入 `/hms` 打开。

```text
https://raw.githubusercontent.com/Laficia/HuntModelSwapCN/main/pluginmaster.json
```

源码与发布：[GitHub 仓库](https://github.com/Laficia/HuntModelSwapCN) · [发布页](https://github.com/Laficia/HuntModelSwapCN/releases)。当前为开发测试版，游戏内效果尚待验证。

也可使用开发插件方式加载本地包：

1. 下载对应 Release 的 `latest.zip`，解压到固定目录；从旧版更新时，先停用插件，再替换文件并重新启用。
2. 在卫月设置 `/xlsettings` → 实验性功能 → 开发插件路径中添加解压后的 `HuntModelSwapCN.dll`，启用该开发插件。
3. 输入 `/hms` 打开窗口。
4. 筛选 S/A/B、SS、SS随从级别和 2.0～7.0 版本，通过「地图」下拉选择狩猎地图，或搜索怪物名称/地图并选择外观。级别与地图默认全部；选择版本后地图选项随之缩小，切换到不兼容版本会自动回到全部地图。「全部地图」按钮只清除地图条件，保留级别、版本和搜索。
5. 「体型倍率」默认填入所选怪物的 `BNpcBase.Scale` 原版缩放值，可以自由输入大于 0 的有限数值，不再限制为 0.1～3 倍；输入值直接作为模型倍率，不再额外乘目标原版体型。切换怪物或点击「恢复所选怪物原版倍率」会重置为该怪原版值。
6. 点击「在我面前生成（本地预览）」即可生成，无需选中小怪。也可选中一只存活的战斗小怪或可攻击木人，点击「替换当前目标」。生成/替换使用当前输入的倍率；已有对象可点击「应用体型到演示对象」调整，无需重新生成。有本地预览时优先调整它，否则调整当前选中且已被替换的目标。
7. 使用「恢复当前目标」「恢复全部」或 `/hms restore` 恢复。

本插件具有独立程序集、命令和窗口；不读取、修改 HHT 配置或狩猎记录，不依赖 HHT、Glamourer 或 Penumbra。

## 简洁界面

常用的选怪、体型、生成和替换操作保留在主界面，隐藏自己与隐藏所有小怪开关仍可直接使用。暂停／旋转、逐只隐藏、技能、台词及说明放在折叠区。展开「隐藏对象与逐只操作」可逐只隐藏／恢复；内部对象列表默认收起，开启「隐藏所有小怪」时收起一次，之后可自由展开，数量变化不会重置展开状态。列表使用固定高度滚动区，避免大量小怪挤占主界面。

「使用说明与目标诊断」默认收起。按钮不能使用时，会显示具体原因，包括未选择外观或无效体型。可点击「复制目标诊断」或输入 `/hms diagnose`，获取当前版本、对象类型、子类型、原始名字 ID、拥有者、血量、模型与加载状态。诊断仅在本机展示或由用户复制，不自动上传。

## 木人替换

0.1.0.18 根据用户实际诊断区分两条路径：

- **庭具木人**：原始 BaseId 901／ModelChara 2449 的 Type 为 0，目标 `Draw=无` 属于布局图形，不是普通角色模型的加载中。选择怪物后点击「替换当前目标」，保留它作为真实训练目标，在其准确位置与朝向生成一个可点击的本地怪物模型，隐藏原庭具图形和重复名牌；新模型显示对应名字、等级、头标与原版体型，动画、暂停和旋转控制它。点击模型／名牌时，硬选中和软选中在目标设置入口映射到原木人；原木人的目标栏和服务器身份／血量保留，替身不产生真实攻击、伤害或状态。也可点击主界面的「选中木人」或输入 `/hms target`。原布局碰撞标志按介入前的值维持，实际碰撞效果仍需游戏内确认。
- **木人歼灭战／探索模式木人**：例如 BaseId 16845／11744，原始模型 Type 为 3，已有正常角色绘制对象，继续直接替换，允许已确认木人的拥有者关联。

庭具原位模型与「在我面前生成」共用现有的一个本地预览位置；再次生成、移除预览、恢复该目标或恢复全部时，会移除替身并还原庭具。切图只丢弃旧会话；原木人消失、模型槽位丢失或 nonce 失效时清理关联，不删除其他对象。新模型 5 秒仍未加载会请求回滚，不无限报告替换成功。0.1.0.20 保留真实木人的绘制状态及原始模型／体型，图形隐藏只作用于庭具布局；恢复和卸载也不对真实木人进行角色模型重绘。诊断总是附加原木人与原位替身的状态，未选中时也可使用 `/hms diagnose`，并记录游戏原生「可选中」判断。原庭具自身保持 `Draw=无` 属于正常情况。更新后请先恢复旧替换，再选中原木人重新替换。

以下为通用替换操作和历史入口修复：

0.1.0.16 仍沿用了普通小怪的入口限制，用户实测出现灰色按钮。0.1.0.17 为已确认的原始木人 `BNpcName` 541／13078 单独放行子类型与父对象关联；不依据可被改写的显示名字识别。原始绘制对象尚未建立时允许准备外观，再由重绘创建模型，技能／暂停仍等待模型实际就绪。非木人的原有过滤保持。

选中游戏里的可攻击木人，选择目标狩猎外观后点击「替换当前目标」。模型、中文名字、显示等级和原版精英头标按所选怪物设置；B 使用蓝色被动头标，A/S/SS 及 SS 随从使用对应的主动精英头标。体型默认是所选怪物的 `BNpcBase.Scale`，直接使用该值，不乘木人的原有大小；仍可手动调整。头顶等级文本另外通过卫月名牌接口更新，避免继续显示木人的缓存等级。

木人被游戏重置、仍是同一对象且模型恢复原状时，插件会按两帧重绘流程重新应用已选外观，不覆盖首次保存的木人原始数据。只对已替换、存活且未处于游戏变身的战斗木人维护此行为；新出现或身份变化的木人需要重新选择替换，不将操作写入复用槽位。点击「恢复当前目标」「恢复全部」或卸载插件，会恢复仍在加载范围内的木人原模型、名字、等级、图标类别和体型，并停止维护。

保留木人的实际身份、血量、受击、仇恨、碰撞与训练机制。名字和等级是本机显示替换，不能把木人变成真实狩猎怪。非战斗装饰家具和未加载对象不在支持范围内，名牌仍遵循游戏显示设置。

## S 怪台词与原生气泡

在 `/hms` 中展开「S 怪台词与原生气泡」，点击「加载／刷新已确认台词库」。生成或替换 S 怪后，在顶部「控制对象」中选择它，点击对应台词旁的「播放气泡」。使用游戏的 NPC 原生气泡，附着模型骨骼，随模型移动与缩放；具体骨骼位置、显示距离及 UI 设置影响实际效果，尚需游戏内验证。

已逐页核对 47 只常规 S 怪的 Wiki 页面，并将有明确台词归属的条目与本机国服 `NpcYell` 表逐条校验。内置内容：

| S 怪 | 原版台词 ID 数 | 去重后的可播放台词 |
| --- | ---: | ---: |
| 先驱勇士 阿提卡斯 | 33 | 16 |
| 天气预报机器人 | 13 | 13 |
| 厌忌之人 奇里格 | 2 | 2 |
| 伊休妲 | 9 | 9 |
| 顾尼图 | 4 | 4 |

其余 42 只目前没有从这些页面确认台词归属，不表示它们不会说话。面板内「47 只 S 怪台词核对清单」可逐项查看。不会将相邻行号或同模型 NPC 的台词自动归给它们；客户端行号对应文本变化时，内置映射会跳过该条。

「收集真实 S 怪的 NPC 台词」默认开启，可关闭。只处理 NPC 对话／NPC 公告频道，发送者名称须完全匹配 S 怪列表，且加载范围内须有真实 `NameId` 对应的 S 怪；使用消息原文，不修改或屏蔽聊天。不收集玩家聊天，也不把本地生成对象当成真实 S 怪。台词按怪物去重、每只最多 128 句，保存到插件配置，重启后仍可使用。未输出到这些频道的气泡不会被此入口收集，不读取旧聊天历史。

阿提卡斯可使用按钮或 `/hms talk` 按用户提供的 0／6／9／13 秒间隔，演示「我们三头……！三位一体，一起干掉你！」「必、必杀……」「三重……」「吐息？」四句气泡。这是台词序列，不会自动施放吐息；其他怪物目前支持逐句播放。`/hms stoptalk` 停止序列并关闭本插件播放的气泡。台词时钟独立于模型动画暂停。

生成、替换、恢复、移除对象前关闭对应演示气泡；切图后不向旧对象写回。仅本机显示，不发出玩家聊天或服务器行动请求；气泡也不额外写入聊天栏。当前没有自动把实战收集的新台词同步播放到预览对象。

## 特殊狩猎与地图

新增三组：克尔的侍从／克尔（6.0）、得到宽恕的流言／得到宽恕的叛乱（5.0）、水晶化身／水晶化身之王（7.0）。每种外观仅列一次，名称、模型、装备、原版倍率和等级按本机数据读取。SS 随从虽然在原始狩猎表的 Rank 列标为 B，但界面单列为「SS随从」并按主动精英显示，普通 B 仍为蓝色被动。

级别下拉新增「SS」「SS随从」，全部仍同时显示各级别。特殊狩猎关联其版本的六张野外地图：选择其中任何一张地图，或搜索对应地图名，均能找到它，不限于原始表中第一次出现的地点。当前仅支持逐只生成／替换，未加入一次生成四个随从或自动触发 SS 战斗。

## 隐藏模型

主窗口顶部提供默认关闭的「隐藏自己模型」和「隐藏所有小怪（保留演示对象）」两个开关。逐只操作：先在游戏中选中一只战斗小怪（主动或被动均可），再点击「隐藏当前目标」。批量开关关闭时只隐藏明确选中的对象，可以继续选其他小怪逐只隐藏。不隐藏其他玩家、宠物或非战斗 NPC。

「隐藏的小怪（可逐只恢复）」列表记录名称与对象索引，每项提供「恢复显示」，不必重新点中已经隐藏的模型。也可使用「恢复当前目标显示」。同名小怪分开管理，换选目标后已隐藏的小怪保持隐藏。已替换外观的真实战斗小怪也可单独隐藏；换模重绘期间等待重绘完成再记录显示状态。

只隐藏模型；名牌、目标栏和独立技能特效仍可能显示，不改变怪物行动、仇恨或伤害。恢复时还原本插件介入前的模型显示位，原本已隐藏的对象保持原状。点击「恢复全部显示」或输入 `/hms show` 可关闭所有隐藏开关并恢复批量与逐只隐藏的对象。切图、登出时清理，卸载时尝试恢复仍存在的对象；对象消失后丢弃记录，不将隐藏应用到复用槽位的新怪。

## 在面前生成（实验）

选择外观后设置前方距离（2～30 米，默认 8 米），点击生成。生成对象面向角色，按角色当前高度放置，不做地面碰撞探测；建议先在平地测试。只保留一个生成对象，再次生成会移除上一个。「移除预览」「恢复全部」和卸载会清理本插件拥有的本地对象；切图后结束本地会话。

这是客户端预览对象，没有真实的服务器狩猎身份或奖励。创建外观后将其真实 `NameId`/`BaseId` 设为 0，显示名称与等级仍使用所选怪物，避免 HHT 根据狩猎名称 ID 误记。生成和技能演示尚需游戏内验证。

本地生成对象隐藏头顶血条，保留所选怪物的中文名字、等级与原版名牌标记。仅在名牌更新中去掉该对象的血条显示位，不修改 HP 或全局名牌设置；直接替换的真实怪物血条保持原样。庭具木人的原位方案隐藏原目标头顶名牌，使用本地模型显示名字、等级与头标，不显示替身头顶血条；真实木人的目标栏血量仍保留。名字、等级的显示仍遵循游戏名牌设置。

本插件拥有的本地预览使用所选 `BNpcBase.Battalion` 阵营，名字／等级由原生敌对怪名牌路径绘制，默认使用未交战怪物配色（通常为黄色），尊重游戏颜色设置。0.1.0.5 曾统一设置 `IsHostile=true`，导致 B 怪也显示主动标记；0.1.0.13 修正为 B 怪被动（蓝色）、A/S 怪主动（红黄色）。精英图形仍取 `BNpcBase.Rank`，不将精英图形类别和狩猎 B/A/S 级别混淆。同一预览换外观后按当前名称与模型重新判断，避免一直沿用最初生成怪物的标记。头顶血条仍隐藏，不复制目标选中箭头。此分类仅用于生成对象，不修改真实小怪的阵营或主动攻击标志。

## 隐藏所有小怪

「隐藏所有小怪（保留演示对象）」与「隐藏自己模型」「隐藏当前目标」同时保留。批量开关默认关闭；开启后持续处理当前加载范围内的主动与被动战斗小怪，新进入加载范围的符合条件对象也会隐藏。不处理玩家、宠物和非战斗 NPC，自动保留本地生成预览与正在替换的演示对象。若明确单独选中演示对象隐藏，逐只隐藏操作仍生效。

批量隐藏期间，列表中的「恢复显示」会为该对象保留显示例外，后续帧不会再自动隐藏它；再次逐只隐藏可取消例外。关闭并重新开启批量开关会清除上次例外。关闭批量开关仅恢复批量隐藏的对象，原来逐只隐藏的对象仍保持隐藏。「恢复全部显示」或 `/hms show` 会关闭全部隐藏开关并恢复插件管理的显示状态；切图、登出和卸载也清理。对象原本已隐藏时不会被强制显示。

## 生成预览的名字高度

0.1.0.8 在模型完成加载后，使用该模型的原生名牌挂点（45，缺失时回退 46）、当前绘制缩放、绘制偏移及原生高度重新计算名牌位置。每次从未缩放挂点计算，放大、缩小及换模型不会累计旧高度；同步当前和目标位置，保留原生额外文字间距。名字、等级与精英标记作为同一原生名牌一起移动。此计算只用于插件仍持有所有权的本地生成对象。

逐只隐藏也不再依赖 `IsHostile` 标志，被动战斗小怪（如蜜蜂云、跳蜥幼体）可以选中后隐藏；宠物和非战斗 NPC 的限制保持，恢复操作沿用原显示状态。若不再选中已隐藏的模型，可从隐藏列表恢复。

## 头顶名称与标记

0.1.0.14 对生成及替换对象按所选怪物的原版精英类别、主动／被动显示分类设置名牌名称前的小图标。普通小怪换 B 怪显示蓝色被动精英图标，换 A/S 怪显示其主动精英图标，连续换不同级别后同步更新，不继承来源怪物的分类。当前 207 种狩猎外观的精英图形类别均为 1，B 与 A/S 分别使用原生资源 61704／61710；未知新图形类别不猜测映射。不会覆盖选中箭头、任务大标记或玩家标记。

该覆盖通过卫月名牌事件仅作用于完整身份匹配的替换对象，本地预览另校验所有权。真实小怪的 `IsHostile`、阵营、仇恨及服务器行为保持；名牌蓝色不代表来源小怪已变成被动。恢复、重绘和未跟踪对象不套用目标图标，恢复原外观并请求重绘后由游戏重新计算原头标；不缓存名牌槽位用于后续写回。卸载后停止覆盖并请求重绘。

0.1.0.2 除维护对象显示名称外，还在卫月名牌更新事件中覆盖已替换对象的头顶名称，处理普通怪或 A 怪换成 S 怪后头顶仍保留原名的情况。目标栏原有名称逻辑保留。

名牌标记类别使用所选怪物的 `BNpcBase.Rank` 写入角色的名牌 `Icon` 字段，并在恢复时还原。本机 201 种 S/A/B 怪都使用同一精英类别；这个标记不区分 S/A/B。最终图标外观仍需游戏内确认。真实对象 `NameId`、`BaseId` 和战斗身份保持不变。

## 动作、旋转与悬浮控制

主窗口顶部提供独立「暂停动作 /hms pause」「恢复动作 /hms resume」按钮，恢复不再取决于界面是否显示已暂停。「控制对象」可自动优先选择本地预览，也可指定任意已生成／替换的演示对象，指定后无需持续选中它。开启「显示悬浮控制窗」或输入 `/hms controls`，可在主窗口关闭时继续控制。

0.1.0.11 修复旧版先覆盖速度缓存、导致原生 SetSlotSpeed 判为数值未变化而不刷新的问题。恢复会通过原生速度接口触发全部 14 个槽的更新；已暂停对象恢复保存的速度，没有暂停记录时也能主动恢复卡在零速的演示对象。建议更新后重新生成预览，再试一次暂停／恢复。

「水平旋转（度）」支持 0～360° 连续调整、左右转 45°和应用角度；可输入 `/hms rotate 90`。旋转后会保持设置朝向，「解除固定朝向」停止维持。暂停期间同样可旋转。这里调整水平朝向，不包含模型俯仰／翻滚。手动旋转会停止布弗鲁自动连招，避免两个控制同时争抢方向；再次启动连招会解除手动朝向。

暂停布弗鲁时，其自动连招剩余倒计时、转向和后续技能调度一同暂停，恢复后继续剩余步骤，不集中补播。暂停期间不能发起新的单次技能或连招，可以调整体型。重新换模、恢复外观、移除／重新生成预览前会恢复对应速度、解除朝向控制；恢复全部和卸载尝试恢复所有速度。切图、所有权丢失或模型变动时丢弃旧记录，不向复用槽位写入。

仅控制本机动画和朝向。真实小怪的服务器位置、攻击判定和伤害仍继续；独立特效、布料和其他物理效果不保证冻结。建议使用本地生成预览。动画接口只在首次主动暂停／恢复请求时启用，打开窗口不会安装动画钩子或修改速度。

狩猎级别默认「全部」，S/A/B 同时显示；可直接点击「全选级别」返回全部。地图默认全部，可按版本缩小地图列表，再与级别、名称搜索共同筛选。

## 技能动作演示（实验）

先生成本地预览或完成小怪模型替换，再展开「技能动作演示（实验）」。若存在本地生成对象，面板和 `/hms play` 优先控制它，无需选中。技能数据只在首次展开此面板或执行播放命令时读取。可以搜索技能名或 Action ID，选择后点击播放；每次播放间隔至少 0.75 秒。聊天栏会报告命令请求结果。

生成或替换为 S/A/B、SS 或 SS 随从后，窗口显示对应技能库及 Wiki 入口。已通过正常浏览器逐页核对全部 207 种外观的技能章节：47 只常规 S 保留原有 300 项；新增 77 A、77 B 与六种特殊狩猎，共 502 项。总计 802 项：

- 346 项以公开 NPC 战斗动作记录核对 ID，340 项按技能名称与本机对应动作资源映射；共 686 项提供直接按钮。资源映射的 ID 用于动画演示，不宣称就是该怪实际使用的 Action ID。
- 100 项存在多个同名动作版本，勾选「显示同名动作版本（需试播确认）」后逐个试播，默认不替用户选择。
- 16 项暂未匹配到可独立播放的本地动作，显示为不可用。
- 对 Wiki 旧译名保留原标签，并校验当前国服名，如「装填环形导弹／装填环状导弹」「石化之眼／石化眼」。客户端动作名或时间轴不匹配时禁用。
- 已有公开记录确认原 NPC 使用的 `mon_sp/gimmick/` 准备／机制时间轴也可点播，但可能只有特效或没有明显动作，不会自动执行后续技能和完整机制。未确认归属的此类通用时间轴不会因名称相同而成为候选。
- 全能机甲、死灰复燃的阿尔宾的人形武器动作按各自 Wiki 技能名与对应剑盾／长枪资源映射，需游戏内确认动画兼容性。

这些菜单用于单次动作演示。目前仅布弗鲁另有自动方向连招，其五个直接按钮如下。技能归属依据用户提供的[灰机 Wiki 布弗鲁资料](https://ff14.huijiwiki.com/wiki/布弗鲁)，ID 与动作文件已按本机国服数据核对：

| 技能 | 指令 |
| --- | --- |
| 巨魔碎颈臂 | `/hms play 27316` |
| 五倍吸气 | `/hms play 27307` |
| 五倍喷嚏 | `/hms play 27309` |
| 上击 | `/hms play 27314` |
| 腐烂孢子 | `/hms play 27313` |

单次按钮播放技能的释放动作（`Action.AnimationEnd`）。布弗鲁另提供下述方向连招；两者均不生成地面范围提示、真实伤害、击退或异常状态。只在本机显示；时间轴中自带的特效可能播放，独立施法/命中特效不保证出现。真实小怪的移动、攻击或服务器更新可能打断动作。不调用真实施法接口，不发送战斗请求。

### 布弗鲁五次吸气 → 五次喷嚏

先生成布弗鲁，或把当前目标替换为布弗鲁，等模型加载完成。在「技能动作演示（实验）」中点击「五次吸气 → 五次喷嚏」，也可输入 `/hms combo`；有本地预览时优先控制它。

- 以连招开始时的朝向为基准，随机记录五次前/右/后/左方向，逐次转向吸气。之后严格按这五个方向的顺序转向喷嚏。
- 咏唱时间从本机国服 Action 表读取：首次吸气 4 秒、重复吸气 0.3 秒，首次喷嚏 5 秒、重复喷嚏 0.3 秒。咏唱阶段通过插件面板倒计时表示，不创建游戏原生咏唱条；计时结束播放对应释放动作。
- 每次释放动作后保留一段停留时间，默认 2 秒，可在 0.75～10 秒内调整。若动作被下一步截断，可增加这个值；当前节奏是演示参数，未宣称还原战斗的精确时间。
- 点击「停止布弗鲁连招」或输入 `/hms stop` 取消剩余步骤；当前动画可能继续播放至结束。正常完成或停止时尝试恢复开始朝向。
- 重新生成、移除预览、换模、恢复、调整体型或单次播放会取消当前连招。切图、登出、重绘、对象消失、所有权丢失或动画接口失败时也会停止，不向复用槽位写回朝向。

连招不会施加睡眠、击倒、病弱或击退，也不进行命中判定。建议用本地生成的布弗鲁演示，避免真实小怪的服务器行为打断动作。

S/A/B 与新增 SS、随从现在均有对应技能库。下方通用候选列表仍可试播未收录动作；同模型资源和通用骨架动作只用于缩小搜索范围，不代表该怪拥有这些技能，也不保证所有候选都兼容。专属技能名称归属来自各自 Wiki 页面，具体动作按上述可信程度区分。若出现动作异常，可恢复当前目标或切图。

## 范围

- 从本机游戏表动态读取中文名称、地图、S/A/B 级别、模型、外观、装备和缩放。本机当前客户端读取 201 种普通狩猎怪（47 S、77 A、77 B），并加入用户指定的 3 SS 和 3 SS 随从，总计 207 种。
- 数值等级使用常规狩猎怪的版本等级映射：2.0 为 50、3.0 为 60、4.0 为 70、5.0 为 80、6.0 为 90、7.0 为 100。S/A/B 级别和数值等级分开显示。
- 只改变本机显示名称、等级与外观；真实名称 ID、基础 NPC ID、技能、血量和奖励仍属于原怪物。HHT 继续按真实名称 ID 识别。
- 对已替换对象维持名称、显示等级和目标体型，避免客户端刷新后变回原显示；只有名称或等级发生变化时才请求刷新名牌。
- 支持同一场景分别替换多只小怪；重复替换同一对象时保留最初外观、原名、原等级与原始缩放供恢复。
- 每次访问重新核验对象表索引、对象 ID、基础 NPC ID、名称 ID 和地址。对象消失后丢弃旧快照，不将其应用于复用该槽位的新对象。
- 替换仅在当前已加载对象上临时生效；切图、离开加载范围后结束，重载插件不会自动替换。卸载时尝试恢复仍存在的对象。
- 当前版本不包含按物种持续自动替换、改变真实狩猎身份、假狩猎记录或网络数据修改。

## 验证结果与待测项目

已通过国服 Dalamud 15.0.3.9 提供的程序集编译（.NET 10、API 15、x64）。离线检查覆盖：

- 201 种狩猎怪分类、名称到模型的映射、所需骨架文件存在。
- 47 只 S 怪的资料名称、模型、Wiki 来源、300 项条目的分类、当前国服动作名称和时间轴一致性、对应模型实际资源存在；旧译名映射及客户端数据变更后禁用。
- 人形 B 怪的模型编号 0 是有效数据，不能当作缺失模型；半人型狩猎怪的装备数据不能省略。
- 原始快照恢复、重复替换、重绘中恢复、对象槽位复用、卸载时单个对象恢复失败不阻断其他对象。
- 技能 ID 与时间轴 ID 的区分、命令参数校验、重绘/恢复/未替换对象拒绝播放、对象槽位复用与 0.75 秒节流；布弗鲁五个技能名称、ID、时间轴和实际动作文件。
- 隐藏自己与逐只隐藏独立生效、多目标与单独恢复、重绘等待、原本隐藏的对象保持原状、显示标记的其他位不被覆盖、恢复失败可重试。
- 本地生成只保留一个对象、重复生成/部分失败清理、所有权标记验证、场景失效及对象槽位复用保护；头顶名称覆盖按完整身份匹配，恢复时使用原名和原标记类别。
- 本地预览只屏蔽头顶血条位，保留文字与其他显示位；真实怪物、已移除的预览和所有权已丢失的复用槽位不受影响。
- 使用合成原生结构检查名称、等级、外观与模型/对象/绘制缩放完整读写及恢复；这些写操作不覆盖名称 ID、基础 NPC ID、HP、位置和碰撞半径字段。
- 201 种中文名称的 UTF-8 长度均适配客户端缓冲区；名称刷新不破坏其他待处理标记，重复替换仍能恢复最初名称与等级。
- 自由输入倍率不再乘目标原版值或限制为 0.1～3；已有对象调整后持续维护新倍率，非法数值拒绝应用，恢复保留最初外观，过期对象不被修改。
- 本地预览阵营取自目标数据，敌对标志更新保留其他角色位、HP、名称 ID、模型、等级和头标；重复刷新不反复请求重绘，所有权丢失后停止写入。
- 布弗鲁连招十次动作和方向重放、首次/后续咏唱时间、取消与朝向恢复、场景/所有权失效不写旧对象、接口失败后停止，以及卡顿后不在一帧突发补播。

以上不能替代游戏内验证。还需要确认不同骨架下的待机、移动、攻击、死亡动画，目标栏与头顶名牌的名称/等级刷新，重绘后的真实体型，以及和其他外观插件的相互影响；普通小怪的技能动画不一定适合新模型。未宣称所有组合都能正常显示。

```powershell
dotnet build src/HuntModelSwapCN -c Release
dotnet run --project tests/HuntModelSwapCN.Tests -c Release
dotnet run --project tests/HuntModelSwapCN.Tests -c Release -- '你的游戏目录/game/sqpack'
```

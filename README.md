# 狩猎模型替换 HuntModelSwapCN

独立于 HHT 的国服卫月插件。可以替换小怪为指定 S/A/B 狩猎外观，或在面前生成本地预览；支持模型、名称、等级、体型和名牌标记，以及隐藏自己和逐只隐藏指定小怪模型。

当前版 0.1.0.4 将批量隐藏改为选中目标后逐只隐藏，并提供恢复列表。体型倍率可自由输入，默认填所选怪物的原版缩放值，可直接应用到已有演示对象。本地生成继续隐藏头顶血条，保留名字、等级与原版名牌标记。321 项离线检查通过，游戏内效果仍需确认。旧版 Release 保留供回退。

## 使用

在线安装：在卫月设置的「第三方插件库」中添加以下订阅地址，保存后到插件安装器搜索「狩猎模型替换」安装。输入 `/hms` 打开。

```text
https://raw.githubusercontent.com/Laficia/HuntModelSwapCN/main/pluginmaster.json
```

源码与发布：[GitHub 仓库](https://github.com/Laficia/HuntModelSwapCN) · [发布页](https://github.com/Laficia/HuntModelSwapCN/releases)。当前为开发测试版，游戏内效果尚待验证。

也可使用开发插件方式加载本地包：

1. 下载对应 Release 的 `latest.zip`，解压到固定目录；从旧版更新时，先停用插件，再替换文件并重新启用。
2. 在卫月设置 `/xlsettings` → 实验性功能 → 开发插件路径中添加解压后的 `HuntModelSwapCN.dll`，启用该开发插件。
3. 输入 `/hms` 打开窗口。
4. 筛选 S/A/B 等级、2.0～7.0 版本，搜索怪物名称或地图，选择外观。
5. 「体型倍率」默认填入所选怪物的 `BNpcBase.Scale` 原版缩放值，可以自由输入大于 0 的有限数值，不再限制为 0.1～3 倍；输入值直接作为模型倍率，不再额外乘目标原版体型。切换怪物或点击「恢复所选怪物原版倍率」会重置为该怪原版值。
6. 点击「在我面前生成（本地预览）」即可生成，无需选中小怪。也可选中一只存活的战斗小怪，点击「替换当前目标」。生成/替换使用当前输入的倍率；已有对象可点击「应用体型到演示对象」调整，无需重新生成。有本地预览时优先调整它，否则调整当前选中且已被替换的目标。
7. 使用「恢复当前目标」「恢复全部」或 `/hms restore` 恢复。

本插件具有独立程序集、命令和窗口；不读取、修改 HHT 配置或狩猎记录，不依赖 HHT、Glamourer 或 Penumbra。

## 隐藏模型

主窗口顶部保留默认关闭的「隐藏自己模型」。小怪改为逐只操作：先在游戏中选中一只敌对战斗小怪，再点击「隐藏当前目标」。只隐藏选中的这只，可以继续选其他小怪逐只隐藏；未选中的小怪保持原样。不隐藏其他玩家、宠物或友方 NPC。

「单独隐藏的小怪」列表记录名称与对象索引，每项提供「恢复显示」，不必重新点中已经隐藏的模型。也可使用「恢复当前目标显示」。同名小怪分开管理，换选目标后已隐藏的小怪保持隐藏。已替换外观的真实敌对小怪也可单独隐藏；换模重绘期间等待重绘完成再记录显示状态。

只隐藏模型；名牌、目标栏和独立技能特效仍可能显示，不改变怪物行动、仇恨或伤害。恢复时还原本插件介入前的模型显示位，原本已隐藏的对象保持原状。点击「恢复全部显示」或输入 `/hms show` 可关闭隐藏自己并恢复逐只隐藏的对象。切图、登出时清理，卸载时尝试恢复仍存在的对象；对象消失后丢弃记录，不将隐藏应用到复用槽位的新怪。

## 在面前生成（实验）

选择外观后设置前方距离（2～30 米，默认 8 米），点击生成。生成对象面向角色，按角色当前高度放置，不做地面碰撞探测；建议先在平地测试。只保留一个生成对象，再次生成会移除上一个。「移除预览」「恢复全部」和卸载会清理本插件拥有的本地对象；切图后结束本地会话。

这是客户端预览对象，没有真实的服务器狩猎身份或奖励。创建外观后将其真实 `NameId`/`BaseId` 设为 0，显示名称与等级仍使用所选怪物，避免 HHT 根据狩猎名称 ID 误记。生成和技能演示尚需游戏内验证。

本地生成对象隐藏头顶血条，保留所选怪物的中文名字、等级与原版名牌标记。仅在名牌更新中去掉该对象的血条显示位，不修改 HP 或全局名牌设置；真实怪物（包括被替换外观的怪物）的血条保持原样。名字、等级的显示仍遵循游戏名牌设置。

## 头顶名称与标记

0.1.0.2 除维护对象显示名称外，还在卫月名牌更新事件中覆盖已替换对象的头顶名称，处理普通怪或 A 怪换成 S 怪后头顶仍保留原名的情况。目标栏原有名称逻辑保留。

名牌标记类别使用所选怪物的 `BNpcBase.Rank` 写入角色的名牌 `Icon` 字段，并在恢复时还原。本机 201 种 S/A/B 怪都使用同一精英类别；这个标记不区分 S/A/B。最终图标外观仍需游戏内确认。真实对象 `NameId`、`BaseId` 和战斗身份保持不变。

## 技能动作演示（实验）

先生成本地预览或完成小怪模型替换，再展开「技能动作演示（实验）」。若存在本地生成对象，面板和 `/hms play` 优先控制它，无需选中。技能数据只在首次展开此面板或执行播放命令时读取。可以搜索技能名或 Action ID，选择后点击播放；每次播放间隔至少 0.75 秒。聊天栏会报告命令请求结果。

生成布弗鲁或把目标替换为布弗鲁后，窗口提供五个战斗技能快捷按钮。技能归属依据用户提供的[灰机 Wiki 布弗鲁资料](https://ff14.huijiwiki.com/wiki/布弗鲁)，ID 与动作文件已按本机国服数据核对：

| 技能 | 指令 |
| --- | --- |
| 巨魔碎颈臂 | `/hms play 27316` |
| 五倍吸气 | `/hms play 27307` |
| 五倍喷嚏 | `/hms play 27309` |
| 上击 | `/hms play 27314` |
| 腐烂孢子 | `/hms play 27313` |

本版播放技能的释放动作（`Action.AnimationEnd`），不模拟完整读条、随机方向顺序、地面范围提示、命中结算、击退或异常状态。只在本机显示；时间轴中自带的特效可能播放，独立施法/命中特效不保证出现。移动、攻击或服务器更新可能打断动作。不调用真实施法接口，不发送战斗请求。

其他怪物可通过候选列表试播；同模型资源和通用骨架动作只用于缩小搜索范围，不代表该怪拥有这些技能，也不保证所有候选都兼容。当前仅布弗鲁提供已人工核对的技能归属。若出现动作异常，可恢复当前目标或切图。

## 范围

- 从本机游戏表动态读取中文名称、地图、S/A/B 级别、模型、外观、装备和缩放。本机当前客户端读到 201 种普通狩猎怪：47 S、77 A、77 B。
- 数值等级使用常规狩猎怪的版本等级映射：2.0 为 50、3.0 为 60、4.0 为 70、5.0 为 80、6.0 为 90、7.0 为 100。S/A/B 级别和数值等级分开显示。
- 只改变本机显示名称、等级与外观；真实名称 ID、基础 NPC ID、技能、血量和奖励仍属于原怪物。HHT 继续按真实名称 ID 识别。
- 对已替换对象维持名称、显示等级和目标体型，避免客户端刷新后变回原显示；只有名称或等级发生变化时才请求刷新名牌。
- 支持同一场景分别替换多只小怪；重复替换同一对象时保留最初外观、原名、原等级与原始缩放供恢复。
- 每次访问重新核验对象表索引、对象 ID、基础 NPC ID、名称 ID 和地址。对象消失后丢弃旧快照，不将其应用于复用该槽位的新对象。
- 替换仅在当前已加载对象上临时生效；切图、离开加载范围后结束，重载插件不会自动替换。卸载时尝试恢复仍存在的对象。
- 当前版本不包含按物种持续自动替换、改变真实狩猎身份、假狩猎记录或网络数据修改。

## 验证结果与待测项目

已通过国服 Dalamud 15.0.3.9 提供的程序集编译（.NET 10、API 15、x64）。离线检查覆盖：

- 201 种狩猎怪分类、名称到模型的映射、所需骨架文件存在。
- 人形 B 怪的模型编号 0 是有效数据，不能当作缺失模型；半人型狩猎怪的装备数据不能省略。
- 原始快照恢复、重复替换、重绘中恢复、对象槽位复用、卸载时单个对象恢复失败不阻断其他对象。
- 技能 ID 与时间轴 ID 的区分、命令参数校验、重绘/恢复/未替换对象拒绝播放、对象槽位复用与 0.75 秒节流；布弗鲁五个技能名称、ID、时间轴和实际动作文件。
- 隐藏自己与逐只隐藏独立生效、多目标与单独恢复、重绘等待、原本隐藏的对象保持原状、显示标记的其他位不被覆盖、恢复失败可重试。
- 本地生成只保留一个对象、重复生成/部分失败清理、所有权标记验证、场景失效及对象槽位复用保护；头顶名称覆盖按完整身份匹配，恢复时使用原名和原标记类别。
- 本地预览只屏蔽头顶血条位，保留文字与其他显示位；真实怪物、已移除的预览和所有权已丢失的复用槽位不受影响。
- 使用合成原生结构检查名称、等级、外观与模型/对象/绘制缩放完整读写及恢复；这些写操作不覆盖名称 ID、基础 NPC ID、HP、位置和碰撞半径字段。
- 201 种中文名称的 UTF-8 长度均适配客户端缓冲区；名称刷新不破坏其他待处理标记，重复替换仍能恢复最初名称与等级。
- 自由输入倍率不再乘目标原版值或限制为 0.1～3；已有对象调整后持续维护新倍率，非法数值拒绝应用，恢复保留最初外观，过期对象不被修改。

以上不能替代游戏内验证。还需要确认不同骨架下的待机、移动、攻击、死亡动画，目标栏与头顶名牌的名称/等级刷新，重绘后的真实体型，以及和其他外观插件的相互影响；普通小怪的技能动画不一定适合新模型。未宣称所有组合都能正常显示。

## 编译与检查

在此目录执行：

```powershell
dotnet build src/HuntModelSwapCN -c Release
dotnet run --project tests/HuntModelSwapCN.Tests -c Release
dotnet run --project tests/HuntModelSwapCN.Tests -c Release -- '你的游戏目录/game/sqpack'
```

默认引用 `%APPDATA%/XIVLauncherCN/addon/Hooks/dev`。其他安装位置可通过 `-p:DALAMUD_HOME=路径` 指定。

当前客户端 2.0～7.0 的完整数据检查预期 321 项通过；后续游戏新增狩猎怪时应相应更新测试中的数量断言与数值等级映射，插件名单和技能候选动态读取。

构建输出在 `src/HuntModelSwapCN/bin/Release/`，卫月打包器生成的压缩包在其 `HuntModelSwapCN/latest.zip`。

Glamourer 的可复用范围和限制见 [RESEARCH.md](RESEARCH.md)。

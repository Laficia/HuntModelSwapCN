# 狩猎模型替换 HuntModelSwapCN

独立于 HHT 的国服卫月插件。把选中的普通小怪在本机显示为指定 S/A/B 狩猎怪物，同时替换模型、名称、数值等级和体型，支持恢复。

当前版 0.1.0.1 已完成编译和离线检查，尚未完成游戏内实测。安装包属于开发测试版。旧版 0.1.0.0 压缩包保留供回退。

## 使用

在线安装：在卫月设置的「第三方插件库」中添加以下订阅地址，保存后到插件安装器搜索「狩猎模型替换」安装。输入 `/hms` 打开。

```text
https://raw.githubusercontent.com/Laficia/HuntModelSwapCN/main/pluginmaster.json
```

源码与发布：[GitHub 仓库](https://github.com/Laficia/HuntModelSwapCN) · [发布页](https://github.com/Laficia/HuntModelSwapCN/releases)。当前为开发测试版，游戏内效果尚待验证。

也可使用开发插件方式加载本地包：

1. 解压 `HuntModelSwapCN-0.1.0.1.zip` 到固定目录；从旧版更新时，先停用插件，再替换文件并重新启用。
2. 在卫月设置 `/xlsettings` → 实验性功能 → 开发插件路径中添加解压后的 `HuntModelSwapCN.dll`，启用该开发插件。
3. 输入 `/hms` 打开窗口，选中一只存活的普通小怪。
4. 筛选 S/A/B 等级、2.0～7.0 版本，搜索怪物名称或地图，选择外观。
5. 点击「替换当前目标」，同时应用名称、数值等级和模型。体型倍率以所选狩猎怪的 `BNpcBase.Scale` 原版缩放为基准，每次选择怪物默认 1.00 倍（真实大小），不会继承原小怪的缩放；可用「设为真实体型」重置倍率。修改倍率后再次点击替换。
6. 使用「恢复当前目标」「恢复全部」或 `/hms restore` 恢复。

本插件具有独立程序集、命令和窗口；不读取、修改 HHT 配置或狩猎记录，不依赖 HHT、Glamourer 或 Penumbra。

## 范围

- 从本机游戏表动态读取中文名称、地图、S/A/B 级别、模型、外观、装备和缩放。本机当前客户端读到 201 种普通狩猎怪：47 S、77 A、77 B。
- 数值等级使用常规狩猎怪的版本等级映射：2.0 为 50、3.0 为 60、4.0 为 70、5.0 为 80、6.0 为 90、7.0 为 100。S/A/B 级别和数值等级分开显示。
- 只改变本机显示名称、等级与外观；真实名称 ID、基础 NPC ID、技能、血量和奖励仍属于原怪物。HHT 继续按真实名称 ID 识别。
- 对已替换对象维持名称、显示等级和目标体型，避免客户端刷新后变回原显示；只有名称或等级发生变化时才请求刷新名牌。
- 支持同一场景分别替换多只小怪；重复替换同一对象时保留最初外观、原名、原等级与原始缩放供恢复。
- 每次访问重新核验对象表索引、对象 ID、基础 NPC ID、名称 ID 和地址。对象消失后丢弃旧快照，不将其应用于复用该槽位的新对象。
- 替换仅在当前已加载对象上临时生效；切图、离开加载范围后结束，重载插件不会自动替换。卸载时尝试恢复仍存在的对象。
- 当前版本不包含按物种持续自动替换、改变真实狩猎身份、假狩猎记录或网络数据修改。

## 验证结果与待测项目

已通过国服 Dalamud 15.0.3.9 提供的程序集编译（.NET 10、API 15、x64）。离线检查覆盖：

- 201 种狩猎怪分类、名称到模型的映射、所需骨架文件存在。
- 人形 B 怪的模型编号 0 是有效数据，不能当作缺失模型；半人型狩猎怪的装备数据不能省略。
- 原始快照恢复、重复替换、重绘中恢复、对象槽位复用、卸载时单个对象恢复失败不阻断其他对象。
- 使用合成原生结构检查名称、等级、外观与模型/对象/绘制缩放完整读写及恢复；这些写操作不覆盖名称 ID、基础 NPC ID、HP、位置和碰撞半径字段。
- 201 种中文名称的 UTF-8 长度均适配客户端缓冲区；名称刷新不破坏其他待处理标记，重复替换仍能恢复最初名称与等级。

以上不能替代游戏内验证。还需要确认不同骨架下的待机、移动、攻击、死亡动画，目标栏与头顶名牌的名称/等级刷新，重绘后的真实体型，以及和其他外观插件的相互影响；普通小怪的技能动画不一定适合新模型。未宣称所有组合都能正常显示。

## 编译与检查

在此目录执行：

```powershell
dotnet build src/HuntModelSwapCN -c Release
dotnet run --project tests/HuntModelSwapCN.Tests -c Release
dotnet run --project tests/HuntModelSwapCN.Tests -c Release -- '你的游戏目录/game/sqpack'
```

默认引用 `%APPDATA%/XIVLauncherCN/addon/Hooks/dev`。其他安装位置可通过 `-p:DALAMUD_HOME=路径` 指定。

当前客户端 2.0～7.0 的完整数据检查预期 237 项通过；后续游戏新增狩猎怪时应相应更新测试中的数量断言与数值等级映射，插件名单本身动态读取。

构建输出在 `src/HuntModelSwapCN/bin/Release/`，卫月打包器生成的压缩包在其 `HuntModelSwapCN/latest.zip`。

Glamourer 的可复用范围和限制见 [RESEARCH.md](RESEARCH.md)。
